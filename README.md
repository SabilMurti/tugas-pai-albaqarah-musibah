## 🚀 Panduan Penggunaan & Cara Salin (Easy to Copas)

### 1. Untuk Makalah (Microsoft Word / Google Docs / LibreOffice)
- Buka berkas `makalah.md`.
- Salin (*copy*) seluruh teks atau per bab.
- Tempel (*paste*) ke Microsoft Word atau Google Docs. Format heading (`#`, `##`), tabel, dan cetak tebal akan otomatis terkonversi rapi.
- Sesuaikan nama penyusun, kelas, dan nama guru pembimbing pada bagian cover.

### 2. Untuk Slide Presentasi (PowerPoint / Canva / Google Slides / Gamma / Marp)
- **Opsi Canva / Gamma.app:** Salin teks dari `ppt.md`, gunakan fitur *Import from Markdown/Outline* atau *Paste text* ke slide layout pilihan Anda.
- **Opsi PowerPoint / Google Slides:** Salin poin-poin dari masing-masing judul slide (`SLIDE 1`, `SLIDE 2`, dst.). Simpan teks di bagian **Speaker Notes** ke dalam kotak catatan presenter di bawah lembar slide PPT Anda.
- **Opsi Marp (VS Code):** Berkas `ppt.md` kompatibel dengan ekstensi Marp for VS Code untuk langsung di-render menjadi PDF atau HTML presentasi.

### 3. Untuk Sesi Diskusi & Tanya Jawab di Kelas
- Buka berkas `tanya_jawab_dan_cheatsheet.md` di smartphone Anda saat sesi presentasi.
- Jika guru atau teman sekelas menanyakan hal-hal rumit seperti: *"Apakah menangis membatalkan sabar?"*, *"Mengapa orang zalim hidupnya enak (istidraj)?"*, atau *"Apa bedanya sabar dengan pasrah tidak mau berobat?"*, Anda sudah memiliki jawaban siap pakai yang didukung dalil shahih Al-Qur'an dan Hadis.
